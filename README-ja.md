## ✨ v1.5.4 の新機能

* **Escキー操作の一元管理:** Escキーの挙動を統一し、より一貫性のある快適な操作性を実現しました。
* **Helpメニューとドキュメントモーダル:** 新たにHelpメニューとアプリ内ドキュメントを追加し、各種ガイドへ素早くアクセスできるようになりました。
* **プレビュー画面での「すべて選択」:** プレビュー画面内で `Ctrl+A` / `Cmd+A` が使用可能になりました。
* **リッチテキストコピーの対応:** プレビュー画面からリッチテキスト形式で直接コピーできるようになりました。
* **ナビゲーション精度の向上:** 検索結果への自動スクロールや、アウトラインからのジャンプ精度を改善しました。

### 🔒 リリースファイルのハッシュ値（チェックサム）について**
セキュリティとファイルの安全性を確保するため、v1.5.4以降のすべての正式リリースにおいて、リリースノートに **SHA-256ハッシュ値** を明記しています。ダウンロードしたファイルが改ざんされていないことを確認したい場合は、OSの標準コマンド（WindowsのPowerShellにおける `Get-FileHash` など）を使用して検証いただけます。

## ✨ 今後のアップデート予定

* **不可視文字の表示:** 全角スペース、タブ、行末の空白、改行などの不可視文字を表示する機能を追加します。
* **Tabキー操作の拡張:** Tabキーによる入力、複数行のインデント、および `Shift+Tab` によるアウトデント操作をサポートします。
* **Zen Modeとフルスクリーン:** 執筆にさらに集中できるフルスクリーン操作と「Zen Mode（集中モード）」を追加します。
* **UIの改善:** タイトルバーのボタンアイコンや、アクティブ状態の視覚的なフィードバックを改善します。
* **セキュリティの強化:** CSPの改善、より安全なWordインポート時のメッセージ表示、SVGデータURLの制限など、小規模なセキュリティアップデートを実施します。
* **ストレージ仕様の明記:** ローカルストレージでの平文保存を防ぐ「自動暗号化」と、パスフレーズでより強固に保護する「プライベートストレージ」の違いや仕様をより分かりやすく記載します。
* **ヘルプの拡充:** キーボードショートカットのドキュメントに、Tab操作、ドキュメントのナビゲーション、選択操作のショートカットを追記します。

## 📝　安全性と透明性

MD//WORKSは完全オープンソースです。HTMLアプリとしてブラウザ上で動作しますが、ドキュメントの処理はすべてローカルの端末内で完結します。編集・保存・書き出し・暗号化など、すべての処理はブラウザ内で実行され、データが外部サーバーに送信されることはありません。

- インストール不要  
- アカウント登録も不要  
- アクセス解析やトラッキングも一切なし

ぜひコードを確認し、ご自身で確かめてください。もし、問題点や潜在的な脆弱性を発見された場合は、Issuesでご報告ください。必要に応じて、非公開でご連絡いただいても構いません。

**※プライバシーに関して**

* **AIを活用したい場合:** ChromeやEdgeなどのブラウザAI（GeminiやCopilot）を使用して文章の校正などを行う場合、テキストは各プロバイダのポリシーに従って処理されます。機密情報を扱う際は、AIサイドパネルを閉じるか、読み取り許可をオフにできます。
* **更にプライバシーを確保したい場合:** **Firefox**や**Brave**など、各AIアシスタントを制御できるブラウザをご使用いただくことで、より安全なエディタとして機能します。

## 🧭 他のエディタとの違い

**MD//WORKSは、IDE、ナレッジベース、共同編集ツールを置き換えることを目的にしたものではありません。**  
MD//WORKSが目指しているのは、もっと別の領域です。  
書くこと、保護すること、復元すること、そして作品を手軽に持ち運ぶことに特化した、軽量でポータブルなMarkdownエディタです。

| 機能 | VS Code | Obsidian | Typora | MD//WORKS |
|---|---:|---:|---:|---:|
| 真のポータビリティ / 単一ファイルApp化 | ❌ | △ | ❌ | ✅ |
| エディタと文書を1つにまとめる | ❌ | △ | ❌ | ✅ |
| 暗号化された単一ファイルとして書き出し | ❌ | ❌ | ❌ | ✅ |
| ローカル完結の暗号化 / サーバー不要 | △ | △ | △ | ✅ |
| 下書き復元・執筆中の安全性 | △ | △ | ❌ | ✅ |
| 集中しやすい執筆環境 | △ | △ | ○ | ✅ |
| オフライン・制限環境での使いやすさ | △ | ○ | ○ | ✅ |
| プラグイン / 拡張機能の豊富さ | ✅✅✅ | ✅✅ | △ | ❌ |

MD//WORKSの特徴

VS Code、Obsidian、Typoraはいずれも優れたツールですが、それぞれ前提としている用途が異なります。

- **VS Code** は、強力な開発環境です。
- **Obsidian** は、知識をつなげて管理するナレッジベースです。
- **Typora** は、完成度の高いMarkdown執筆アプリです。
- **MD//WORKS** は、別の考え方で設計されています。  
  **書いたものを、保護し、1つのファイルとして持ち運ぶためのMarkdownエディタ**です。

**Save as App** と **Private App export** により、MD//WORKSはMarkdown文書を、持ち運び可能なHTMLアプリとして書き出せます。  
目的は機能をむやみに増やすことではなく、大切な文章をより簡単に移動・保管・再編集・保護できるようにすることです。

クラウドに依存せず、インストールも不要。  
MD//WORKSは、文章とエディタをひとつにまとめて持ち運ぶための、新しいローカルファーストなMarkdownワークフローを提案します。
