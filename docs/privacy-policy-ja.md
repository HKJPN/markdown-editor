# MD//WORKS プライバシーポリシー

日本語 | [English](privacy-policy.md)

最終更新日：2026年10月19日  
提供者：HKJPN  
対象：MD//WORKS（Web版・PWA版・Microsoft Store配布版）

## 1．基本方針

MD//WORKS（以下「本アプリ」）は、利用者の端末内で文書を編集・処理することを基本とするMarkdownエディターです。

本ポリシーは、本アプリが取り扱う情報、その利用目的、保存方法、外部通信、および利用者による管理方法を説明します。

## 2．文書・ファイルの取り扱い

本アプリは、利用者が入力、選択、貼り付け、または読み込んだ文章、ファイル名、画像、文書に含まれる情報を、編集・プレビュー・変換・保存・出力のために端末内で処理します。

これらの情報には、利用者が文書に記載した個人情報が含まれる場合があります。

本アプリは、文書内容、ファイル名、作業履歴、保存用パスフレーズを、提供者のサーバーへ自動送信しません。提供者による文書のクラウド保存や同期は行いません。

ファイルへのアクセスやクリップボードの利用は、ファイルを開く、保存する、コピーする、貼り付けるなどの利用者の操作と、OS・ブラウザの権限管理に従って行います。

## 3．端末内に保存する情報

本アプリは、次の情報をブラウザまたはアプリのローカル保存領域に保持します。

- 編集中の文書、文書名、自動保存データ
- 文書の作業履歴
- テーマ、表示方法などの設定
- 更新確認日時や取得したバージョン情報

保存にはLocal Storage、IndexedDBなどを使用します。自動保存する文書・履歴には暗号化処理を使用し、Private Storage機能では利用者のパスフレーズによる保護を追加できます。表示設定など、すべての保存情報が暗号化されるわけではありません。

保存情報は、利用者による削除、ブラウザ・OSによる保存領域の消去などが行われるまで端末内に保持されます。ローカル保存はバックアップや永続的な保持を保証するものではありません。

利用者が保存先としてOneDriveなどの同期対象フォルダーを選んだ場合、そのファイルの同期は、利用者が使用するOSやクラウドサービスの設定・規約に従います。

## 4．Deep編集モード

利用者がDeep編集モードを有効にした場合、編集時刻、編集操作、文字数の変化、ファイル名、挿入・削除した文章の一部などを端末のメモリ上に記録します。

このログは本アプリから外部へ自動送信されず、ページの再読み込みで消去されます。また、利用者はログ消去機能で削除できます。

利用者がログをコピー、保存、または他のサービスに貼り付けた場合、そのコピーは別途残ります。ログには削除済みの文章や個人情報が含まれる可能性があるため、共有前に内容を確認してください。

## 5．外部サービスへの通信

本アプリは、配信、更新確認、および機能に必要なリソースの取得のため、次の外部サービスへ接続します。

| 接続先 | 主な目的 |
| --- | --- |
| GitHub Pages | アプリ本体や関連ファイルの配信 |
| GitHub API | 最新リリースの確認 |
| GitHub | 利用者の操作による説明書・リポジトリ・問い合わせページの表示 |
| jsDelivr | 一部のライブラリ、辞書、数式・図表表示などに必要なファイルの取得 |
| Google Fonts | 表示用フォントの取得 |

これらの通信に伴い、接続先にはIPアドレス、リクエスト日時、要求したURL、ブラウザ・OSに関する情報などが伝わる場合があります。文書内容や作業履歴を、これらの通信の送信データとして付加することはありません。

各サービスによる接続情報の保存・利用・保護は、各提供元のポリシーに従います。

- [GitHubのプライバシーステートメント](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)
- [jsDelivrのプライバシーポリシー](https://www.jsdelivr.com/terms/privacy-policy)
- [Googleのプライバシーポリシー](https://policies.google.com/privacy)
- [Microsoftのプライバシーステートメント](https://privacy.microsoft.com/privacystatement)

Microsoft Store、Windows、Microsoft Edgeによる情報の取り扱いも、それぞれの設定およびMicrosoftのポリシーに従います。

## 6．AIサービス・外部リンク

本アプリは、文書や編集ログをAIサービスへ自動送信しません。

利用者がブラウザのAIサイドバー、拡張機能、外部AIサービスなどへ文章やログを渡した場合、その情報は利用者が選択したサービスの設定・規約・プライバシーポリシーに従って処理されます。

本アプリから外部リンクを開いた場合も、リンク先の情報の取り扱いは、そのサイトのポリシーに従います。

## 7．広告・分析・第三者への提供

本アプリには、独自の広告配信、広告目的の追跡、文書内容や編集操作を提供者へ送信する行動分析機能を組み込んでいません。

提供者は、本アプリの文書内容や作業履歴を販売せず、広告目的で第三者に提供しません。

## 8．情報の確認・削除・安全管理

利用者は、本アプリ上で文書や履歴を確認し、編集・保存・削除できます。

- 自動保存した文書・履歴は「ローカル保存データ削除」などの機能で削除できます。
- 設定を含む保存情報は、ブラウザまたはアプリ実行環境のサイトデータ削除機能で消去できます。
- 通常のファイルとして保存・出力したデータは、保存先で別途削除してください。
- ローカル保存データを削除しても、現在画面に表示されている文書や、外部に保存したコピーは自動では削除されません。

提供者は、利用者の端末内にのみ保存された文書や履歴を取得・復元・削除することはできません。

本アプリはローカルでの処理、保存データの暗号化、外部リソースの整合性検証などにより情報の保護を図ります。ただし、端末自体の不正利用や、利用者が外部へ共有した情報まで保護を保証するものではありません。

## 9．問い合わせ

本アプリおよび本ポリシーに関する問い合わせは、次の窓口で受け付けます。

[MD//WORKS GitHub Issues](https://github.com/HKJPN/markdown-editor/issues)

問い合わせに含まれるGitHubユーザー名、投稿内容、添付ファイルなどは、問い合わせへの回答、不具合の調査、必要な対応記録の保持のために取り扱います。

GitHub Issuesへの投稿は公開されます。個人情報、機密文書、パスワードなどを投稿しないでください。投稿の保存・削除については、GitHubの機能およびポリシーも適用されます。

## 10．本ポリシーの変更

本アプリの機能や情報の取り扱いの変更に応じて、本ポリシーを更新します。変更後の内容と最終更新日を本ページに掲載します。重要な変更については、必要に応じてアプリ内または配布ページでもお知らせします。
