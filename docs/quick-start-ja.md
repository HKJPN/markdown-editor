# MD//WORKS Manual

## 1. はじめに

MD//WORKSは、ブラウザで動く多機能軽量Markdownエディタです。
インストール不要で、Markdown文書の作成、プレビュー、保存、HTML出力などができます。現在の文書とエディタを1つのHTMLファイルとして保存することもできます。


## 2. 基本操作

### 新規作成
File > New から新しい文書を作成できます。

### ファイルを開く
File > Open から `.md` や `.txt` ファイルを開けます。

### 保存
Save または Download からMarkdownファイルとして保存できます。

### プレビュー
Previewボタンで、Markdownの表示結果を確認できます。

## 3. 編集機能

- 見出し
- 太字・斜体
- 箇条書き
- 番号付きリスト
- タスクリスト
- 引用
- コードブロック
- 表
- リンク

## 4. Wordファイルの読み込み

`.docx` ファイルを読み込み、Markdown形式に変換できます。
一部の複雑なレイアウトは簡略化される場合があります。

## 5. スタンドアロン保存

Save as App を使うと、現在の文書とエディタを1つのHTMLファイルとして保存できます。

## 6. よくある質問

### インストールは必要ですか？
不要です。ブラウザで動作します。

### クラウドにアップロードされますか？
通常の編集・保存処理はブラウザ内で完結します。

### どのブラウザがおすすめですか？
PC/Mac版のChromeまたはEdgeを推奨します。その他のブラウザでも、自動認識され必要な機能が使えるよう設計しています。
