# MD//WORKS Manual

## 1. はじめに

MD//WORKSは、ブラウザで動く多機能軽量Markdownエディタです。
Markdown文書の作成、プレビュー、保存、HTML出力などができます。現在の文書とエディタを1つのHTMLファイルとして保存することもできます。

## 2. インストール
面倒な設定やインストールは一切ありません。
下記のリンクをクリックするだけで、今すぐエディターを体験できます！
👉 https://hkjpn.github.io/markdown-editor/

## 3. 基本操作

### 新規作成
File > New から新しい文書を作成できます。

### ファイルを開く
File > Open から `.md` や `.txt` ファイルを開けます。

### 保存
Save または Download からMarkdownファイルとして保存できます。

### プレビュー
Previewボタンで、Markdownの表示結果を確認できます。

## 4. 編集機能

- 見出し
- 太字・斜体
- 箇条書き
- 番号付きリスト
- タスクリスト
- 引用
- コードブロック
- 表
- リンク

## 5. Wordファイルの読み込み

`.docx` ファイルを読み込み、Markdown形式に変換できます。
一部の複雑なレイアウトは簡略化される場合があります。

## 6. スタンドアロン保存

Export as App を使うと、現在の文書とエディタを1つのHTMLファイルとして保存できます。

## 7. よくある質問

### インストールは必要ですか？
不要です。ブラウザで動作します。

### クラウドにアップロードされますか？
いいえ。全ての編集・保存処理はブラウザ内で完結します。クラウドにアップロードされることはありません。

### どのブラウザがおすすめですか？
Chrome、Brave, Firefox, Safari, Edge等で動作確認を行っおります。各ブラウザは自動認識され、必要な機能が使えるよう設計しています。AI支援執筆にはデスクトップ環境においてChromeとBraveがおすすめです。iPadにおいては標準のSafariではAI支援執筆ができませんが、Braveを使うことで可能になります。
