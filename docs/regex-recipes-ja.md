## 1. そのまま使える実用パターン (基本編)

*   **行頭の空白を削除:** 検索 `^\s+` 置換 `` 空
*   **行末の空白を削除:** 検索 `\s+$` 置換 `` 空
*   **空行を削除:** 検索 `^\n` 置換 `` 空  または `^$\n`
*   **数値を全部抜き出す:** `\d+` 少数含むなら `-?\d+(\.\d+)?`
*   **HTMLタグを全部消す:** `<[^>]+>`
*   **ダブルクォート文字列:** `"[^"]*"`  シングルなら `'[^']*'`
*   **`//` コメント行:** `^\s*//.*$`

## 2. そのまま使える実用パターン (発展編)

**テキスト編集・チェックで光るワザ**

* **連続する重複単語を見つける（例：「the the」など）:** 検索 `\b(\w+)\s+\1\b`
* **解説:** 英語の文章などで、うっかり同じ単語を2回連続で書いてしまったミスを見つけるのに役立ちます。検索側で `\1`（1番目のグループと同じ内容）を使う面白い例です。


* **MarkdownのリンクからURLだけを取り出す:** 検索 `\[(.*?)\]\((.*?)\)` 置換 `\2`
* **解説:** `[リンクテキスト](URL)` の形式からURLだけを抽出します。置換を `テキスト: \1, URL: \2` とすれば、リスト化するのにも使えます。


* **時刻（HH:MM）だけを厳密に探す:** `\b([01][0-9]|2[0-3]):[0-5][0-9]\b`
* **解説:** 単純な `\d{2}:\d{2}` だと「99:99」のような無効な時間にも一致してしまいますが、これなら「00:00」から「23:59」までにしか一致しません。



**「先読み・後読み」を使った高度なワザ**

* **特定のキーワードを「含まない」行を抽出する:** `^(?!.*除外したい言葉).*$`
* **解説:** `(?!...)` は「否定先読み」と呼ばれるテクニックです。ログファイルから特定のエラーだけを除外して見たい時などに威力を発揮します。


* **「特定の文字の後」にある文字だけを置換・抽出する:** 検索 `(?<=Price: )\d+`
* **解説:** `(?<=...)` は「肯定後読み」です。「Price: 1000」という文字列があった場合、「Price: 」の部分には一致せず、その直後にある数字の「1000」だけをターゲットにします。


* **数字に3桁区切りのカンマを入れる（1000000 → 1,000,000）:** 検索 `(?<=\d)(?=(\d{3})+(?!\d))` 置換 `,` カンマ
* **解説:** 一見呪文のようですが、文字そのものではなく「数字と数字の間の、後ろに3桁の数字が続く隙間」に一致させてカンマを挿入する、正規表現のパズル的な面白さが詰まった定番パターンです。



## 3. 文字と繰り返し - 基本

| 記号 | 意味 | 検索パターン例 | 対象文字列 / 一致結果 | 解説 |
| --- | --- | --- |--- |--- |
| **.** | 任意の1文字 | `a.c` | `abc`, `a1c`, `a c` は一致 / `ac` は不一致 | `...` なら任意の3文字 |
| **\*** | 直前の0回以上 *1最長 | `ab*c` | `ac` `abc` `abbbc` すべて一致 | `.*` で行全体。`a*` は空文字にも一致するので注意 |
| **+** | 直前の1回以上 *1最長 | `ab+c` | `abc` `abbbc` は一致 / `ac` は不一致 | `a+` は `aaa` を1塊で取る |
| **?** | 直前の0か1回 *1最長 | `ab?c` | `ac` `abc` は一致 / `abbc` は不一致 | `https?` で `http` と `https` 両方に一致 |
| **\*?** | 直前の0回以上 *2最短 | `<.*>` vs `<.*?>` | 対象: `<b>aaa</b><b>bbb</b>` <br>`<.*>` → `<b>aaa</b><b>bbb</b>` 全体 <br>`<.*?>` → `<b>` のみ | HTMLタグを1つずつ取りたい時は必ず `*?` を使う。最長と最短の代表例 |
| **+?** | 直前の1回以上 *2最短 | `a.+?c` | `abbbcbbbc` に対して `abbbc` で止まる。`a.+c` なら最後の `c` まで取る | |
| **??** | 直前の0か1回 *2最短 | `ab??c` | `abbc` のような場合に空を優先 | ほとんどは `*?` `+?` を使う |
| **[ ~ ]** | [ ]の中のどれか1文字 *5 | `[abc]` `[0-9]` `[a-zA-Z]` | `gray` に `gr[ae]y` → `gray`と`grey`両方に一致 | 範囲は `[ -~ ]` ではない。中では `.` `*` は普通の文字 |
| **[^ ~ ]** | [ ]の中に無い1文字 | `[^0-9]` `[^ \t]` | `a[^0-9]b` → `a-b` は一致 `a1b` は不一致 | `[^"]*` で `"` 以外の文字列＝引用符の中身を取る定番 |
| **( ~ \| … )** | どれか | `(cat\|dog)` `(png\|jpg\|gif)` | `cat` か `dog` に一致 | `( )` が無いと `ab|cd` は `ab` か `cd` になる |
| **{n}** | 直前のn回 | `\d{4}` | `2026` に一致。郵便番号 `\d{3}-\d{4}` | |
| **{min,max}** | min以上max以下 *1最長 | `\d{2,4}` `a{2,}` `a{,3}` | `12345` に `\d{2,4}` → `1234` に一致。`{2,}`は2回以上、`{,3}`は3回以下 | |
| **{min,max}?** | min以上max以下 *2最短 | `a{2,4}?` | `aaaaa` に対して `aa` で止まる。`a{2,4}` なら `aaaa` を取る | |
| **( ~ )** | グループ化 | `(ab)+` `(https?://\S+)+` | `ababab` に `(ab)+` は全体一致。`ab+` は `abbb` なので全く違う | 繰り返しと置換 `\1` の両方で必須 |

## 4. 文字クラス - 便利系

| 記号 | 検索例 | 実例 |
| --- | --- | --- |
| **\w** | `[A-Za-z0-9_]` | `\w+` → `var1`, `_test` に一致。プログラムの識別子を取る定番 |
| **\W** | `\w`以外 | `\W+` で単語区切りで分割できる |
| **\d** | `[0-9]` | `\d+` → `123` / 日付 `\d{4}/\d{2}/\d{2}` → `2026/07/17` |
| **\D** | 数字以外 | `\D+` → 数字以外を塊で |
| **\s** | 空白,タブ,改行 | `\s+` で連続する空白を1つに潰す置換で使う |
| **\S** | 空白以外 | `https?://\S+` でURL抽出、`\S+@\S+` で簡易メール抽出 |
| **\n** | 改行 | `\n\n` で空行1つを検索 |
| **\t** | タブ | `\t+` で連続タブ |
| **\\** | \そのもの | `C:\\Windows` を探すなら `C:\\\\Windows` と検索する必要がある |

## 5. 位置系 - 文字ではなく「隙間」に一致

| 記号 | 意味 | 実例 |
| --- | --- | --- |
| **^** | 行の先頭 | `^#` → 行頭の `#`。Markdownの見出し検索。`^\s+` → 行頭のインデント |
| **$** | 行の末尾 | `\s+$` → 行末の余分な空白。`;$` → 行末がセミコロンで終わる行 |
| **\<** | 単語の先頭 | `\<cat` → `cat` `category` には一致するが `bobcat` にはしない |
| **\>** | 単語の末尾 | `cat\>` → `cat` `bobcat` には一致するが `cats` にはしない |
| **\b** | 単語の境界 | `\bcat\b` → `cat` 単体のみ。`category` にも `bobcat` にも一致しない。最もよく使う |
| **\B** | 単語の途中 | `\Bcat\B` → `concatenate` の中の `cat` のように前後が単語文字で繋がっている場所 |
| **\A** | ファイルの先頭 | `\A#!/` → ファイル先頭のシバンだけに一致。`^` は各行で一致するが `\A` はファイル1回のみ |
| **\z** | ファイルの末尾 | `\n\z` → ファイル末尾の最後の改行だけに一致 |
| **\G** | 直前の一致の末尾 | 置換を連続でかける時に使う。例: CSVで `^` から始めて `\G[^,]*,` を繰り返し検索すると1フィールドずつ進める |

## 6. 置換文字列で使う記号

検索側と意味が全く違うので注意。

| 記号 | 置換例 | 結果 |
| --- | --- | --- |
| **\0** | 検索 `\w+` 置換 `[\0]` <br>対象 `abc` | `[abc]`  一致全体を再利用 |
| **\1 \2 ...** | 検索 `(.*)=(.*)` 置換 `\2=\1` <br>対象 `key=value` | `value=key`  左右入れ替え。*4 番号は `(` が出てきた順 |
|  | 検索 `(\d{4})/(\d{2})/(\d{2})` 置換 `\2-\3-\1` | `07-17-2026` のように並べ替え |
| **\l \L \E** | 検索 `(\w+)` 置換 `\L\1\E` | すべて小文字化。`\l\1` なら先頭1文字だけ小文字 |
| **\u \U \E** | 検索 `(\w+)` 置換 `\U\1\E` | すべて大文字化。`hello` → `HELLO` <br>`\u\1` なら `hello` → `Hello` にできるのでキャメル化に便利 |
| **\n \t \\** | 検索 `;` 置換 `;\n` | セミコロンの後ろで改行。CSVのカンマをタブに変える `\t` も定番 |
