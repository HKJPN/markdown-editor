# Scientific WritingにおけるMarkdown活用マニュアル

学術論文やレポートの執筆において、Wordなどのワープロソフトはレイアウト調整に気を取られがちです。Markdownを使用すれば、「文章の構造」と「見た目」を完全に分離できるため、執筆の思考プロセスを途切らせることなく、タイピングに没入できます。

本セクションでは、生命科学や技術分野の執筆で特に役立つ高度な記述法と、エディタの**入力補助ボタン**を使った効率的な執筆術を解説します。

## 1. 引用と注釈のスマートな管理（脚注）

論文執筆において、膨大な先行研究や参考文献の番号を手動で管理するのは非常に手間です。Markdownの脚注機能を使えば、システムが自動で美しい連番を生成します。

**■ 思考を止めない「仮ラベル」の活用**
脚注のカッコ内には、数字だけでなく**任意のアルファベットや単語**を入れることができます。執筆中は「とりあえずのキーワード」を入れておき、番号管理はシステムに任せてしまいましょう。

**【入力例】**

```markdown
細胞の初期化プロセスにおいて、〇〇の因子が重要であることが示唆されている[^takahashi2006]。
また、最新のスクリーニング手法を用いることで、効率的な特定が可能になった[^screening_method]。
さらに検証を進める[^memo]。

[^takahashi2006]: Takahashi & Yamanaka (2006) Cell...
[^memo]: ここに後で追加の考察を書く
[^screening_method]: 〇〇の手法についての詳細なプロトコル

```

**【プレビューでの表示】**
プレビュー画面では、入力した仮のラベルは無視され、**本文の上から登場した順番に「1, 2, 3...」と自動で綺麗な連番に振り直されます。** 後から文章の順番を入れ替えても、自動的に再計算されるため番号がズレる心配はありません。

## 2. 科学・化学記号の記述（上付き・下付き文字）とテキスト強調

生命科学分野で頻出する化学式、イオン価数、統計の有意差（p値）などの表記も、マウスを使わずにキーボードのみで完結します。また、ツールバーの装飾ボタンを使うことで、素早く書式を適用できます。

**■ 下付き文字（Subscript）**
テキストをチルダ（`~`）で囲むと、下付き文字として表示されます。主に化学式などで使用します。

* **入力:** `H~2~O` ➔ **表示:** H₂O
* **入力:** `CO~2~ インキュベーター` ➔ **表示:** CO₂ インキュベーター

**■ 上付き文字（Superscript）**
テキストをキャレット（`^`）で囲むと、上付き文字として表示されます。イオンやべき乗、単位面積などに使用します。

* **入力:** `Ca^2+^` ➔ **表示:** Ca²⁺
* **入力:** `p < 0.05^*^` ➔ **表示:** p < 0.05*

**💡 エディタの補助機能を活用する**
文字を選択した状態でツールバーのボタンを押すと、自動でマークダウン記号が挿入されます。

* **遺伝子名や学名のイタリック（斜体）表記:** 文字を選択して **`[I]`** ボタンを押すと、`*学名*` のようにアスタリスクで囲まれます。
* **統計的有意差や重要項目の太字強調:** 文字を選択して **`[B]`** ボタンを押すと、`強調` のようにダブルアスタリスクで囲まれます。

## 3. 高度なデータ表（Table）の作成

実験条件の比較や、解析データの整理には表（テーブル）が不可欠です。Markdownではテキストだけで直感的に表を作成できますが、手動でパイプ（`|`）やハイフン（`-`）を打ち込むのは骨が折れます。

ここでエディタ上部の **`[⊞ Table]`** ボタンが真価を発揮します。

**■ ボタン一発でテーブルの骨組みを挿入**
表を挿入したい行でツールバーの **`[⊞ Table]`** ボタンをクリックすると、以下のような標準的な表のテンプレートがエディタ内に一瞬で生成されます。

```markdown
| ヘッダー | ヘッダー |
| --- | --- |
| セル | セル |

```

あとは、このテンプレートの文字を自分の実験データに書き換えるだけです。

**■ 列の配置（左寄せ・中央揃え・右寄せ）の制御**
2行目のハイフン（`-`）とコロン（`:`）の組み合わせを変更することで、列ごとの文字の配置を綺麗にコントロールできます。特に数値データは「右寄せ」にすると格段に見やすくなります。

* `:---` （左寄せ）
* `:---:`（中央揃え）
* `---:` （右寄せ：数値データに最適）

**【入力例（書き換え後）】**

```markdown
| 実験群 | 処理濃度 (µM) | 細胞生存率 (%) | 判定 |
| :--- | ---: | ---: | :---: |
| Control (Vehicle) | 0.0 | 100.0 | - |
| Treatment A | 10.5 | 82.4 | N.S. |
| Treatment B | 50.0 | 45.1 | **\*** |

```

※表のような複雑な表記は、エディタ右側の**プレビュー画面**をリアルタイムで確認しながら記述すると、構造の崩れ（パイプの過不足など）をその場ですぐに修正できて便利です。

## 4. 数式の表現（Math / LaTeX）

論文やレポートに不可欠な複雑な数式も、LaTeX（ラテフ）記法を用いて美しく記述できます。数式を文章の中に埋め込むか、独立した行として強調するかで記法を使い分けます。

**■ インライン数式（文章中に埋め込む）**
数式を `$`（ドルマーク1つ）で囲むと、文章の行内に自然なサイズで数式が配置されます。

* **入力:** `アインシュタインの質量とエネルギーの等価性を示す式は $E = mc^2$ である。`
* **表示:** アインシュタインの質量とエネルギーの等価性を示す式は $E = mc^2$ である。

**■ ディスプレイ数式（独立したブロックで表示）**
数式を `$$`（ドルマーク2つ）で囲むと、中央揃えの独立したブロックとして数式が大きく強調表示されます。複雑な方程式や積分・行列などに適しています。

**【入力例】**

```markdown
正規分布の確率密度関数は以下のように定義されます。

$$
f(x) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)
$$

```

**【プレビューでの表示】**
正規分布の確率密度関数は以下のように定義されます。

$$f(x) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$$

## 5. 技術文書・解析データのためのコード記述（Code）

RNA-Seqなどの解析スクリプトや、統計解析（RやPythonなど）のソースコードを記述・共有する際に非常に便利です。エディタのツールバーボタンを使えば、簡単に専用の枠組みを作成できます。

**■ インラインコード（文章中のプログラム用語）**
関数名やファイル名などを本文中で明確に区別したい場合は、バッククォート（```）で囲みます。

* **入力:** `解析には main.py スクリプトを使用し、 print() 関数で出力した。`
* **表示:** 解析には `main.py` スクリプトを使用し、 `print()` 関数で出力した。
* **💡 エディタの補助機能を活用する:** 文字を選択してツールバーの **`[` `]`** ボタンを押すと、一発でインラインコードとしてハイライトされます。

**■ コードブロック（複数行のソースコード）**
複数行にわたるコードを記述する場合は、バッククォート3つ（`````）で囲みます。
手動で打ち込まずとも、ツールバーの **`[{ } Code]`** ボタンをクリックするだけで、一瞬でコードブロックの入力テンプレートが挿入されます。

**■ シンタックスハイライト（言語指定による色分け）**
開始の ````` の直後にプログラミング言語名（`python`, `r`, `bash`, `html` など）を指定すると、その言語の構文に合わせて自動的にコードが色分け（シンタックスハイライト）され、論文やマニュアルにおける可読性が飛躍的に向上します。

**【入力例】**

```python
import pandas as pd
import matplotlib.pyplot as plt

# データを読み込んで細胞生存率の平均を計算
data = pd.read_csv("cell_data.csv")
mean_survival = data['survival_rate'].mean()
print(f"Mean Survival: {mean_survival}%")
```
**【プレビューでの表示】** 
プレビュー画面では、Pythonの文法にしたがって、impoortのハイライト、ストリングス、コメントラインが色分けされて表示されます。
