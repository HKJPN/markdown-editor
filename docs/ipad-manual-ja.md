# MD//WORKS Editor 取扱説明書 (iPad)

MD//WORKS Editorは、文章作成、プレビュー、保存・書き出し、ブラウザAIなどに幅広く対応した1ファイル完結型のMarkdownエディタです。iPadでは、黒背景の「Midnight」テーマに設定すると、Apple Pencilでの手書き入力が一段と快適になります。また、「ファイル」アプリを活用することでMacやPCと変わらない、あるいはそれ以上に安全で便利な**ファイル保存(共有)**が可能です。

## 本書の画像注釈について

本書では、画面内の操作箇所を枠線や番号で示します。  
赤枠はクリック・選択する場所、青枠は確認する表示、丸数字は操作順を表します。

## 1. 起動と画面構成

### 1-1. 起動する

インストール不要で、次のサイトからブラウザ上で起動ができます: 👉 [MD//WORKS Editor](https://hkjpn.github.io/markdown-editor/)
ローカルに保存されたHTMLファイルをブラウザで開くことでも起動します（※常に最新の機能や修正が適用された状態で利用するためには、上記のWebサイトからの起動がおすすめです）。

ファイルを開いた直後から、エディター画面にテキストの入力が可能です。前回の未保存データが残っている場合は、復元確認が表示されることがあります。復元する場合は確認画面で復元を選択してください。

>💡 iPadをより快適に使うヒント： Safariの共有ボタン（四角から上矢印が出ているアイコン）から『ホーム画面に追加』を選ぶと、アイコンが追加され、次回から通常のアプリと同様に起動できます。

### 1-2. 対応環境

MD//WORKS Editor は、以下のiPad環境で快適にご利用いただけます。

* **対応機種（目安）**
  * iPad（第6世代以降）
  * iPad Pro（第1世代以降）
  * iPad mini（第5世代以降）
  * ※上記と同等以降の性能を持つiPad Airなどでもご利用いただけます。

* **推奨ブラウザ**
  * Safari、Chrome、Brave、Firefox
  * ※安全のため、最新のセキュリティアップデートが適用されたiPadOSでお使いください。

* **対応アクセサリー（任意）**
  * Apple Pencil（または互換品）
  * 外付けキーボード（Magic Keyboardなど）
  * マウス、トラックパッド

### 1-3. 画面構成

![Image: Overall screen layout with numbers ① to ⑥ indicating each area](<./images/overall-screen-layout-ja.jpg>)

* **① メニューバー**  
  ファイル、編集、表示、ヘルプの各メニューへアクセスします。ファイルの新規作成、保存（共有）、書き出し、表示切替、ヘルプ確認などを行います。

* **② タイトルバー**  
  アプリ名、ファイル名、保存状態、主要な操作ボタンが表示されます。  
  ファイルを開く、保存する、Previewを切り替える、全画面表示にする、Spell (EN) を使うなどの操作をすばやく行えます。

* **③ ツールバー**  
  見出し、太字、斜体、リスト、タスク、引用、コード、リンク、表などをワンクリックで挿入できます。  
  Markdownに慣れていない場合でも、基本的な書式を簡単に入力できます。

* **④ エディター画面**  
  Markdown形式で本文を入力するメインエリアです。  
  テキストの編集、見出し作成、リスト作成、画像の挿入などを行います。

* **⑤ プレビュー画面**  
  入力したMarkdownを整形して表示する画面です。  
  実際の見た目を確認しながら編集できます。プレビューは、タイトルバーの **Preview** ボタンまたは **表示 > Preview** から切り替えできます。

* **⑥ ステータスバー**  
  現在の行数、単語数、文字数、Spell (EN) の状態、ストレージ保護モードが表示されます。  
  ストレージ保護モードには、通常の **Auto encrypted** と、パスフレーズを使う **Private Storage** があります。

> 💡 Safariをご利用の場合ブラウザURLバー左側の『ぁあ（または AA）』ボタンをタップでさらに次の表示設定が可能です。
> - ツールバーを非表示にして画面を広く使う
> - ページの拡大率を85%〜100%の間で調整

## 2. ファイルを作成・開く

![Image: ファイルを作成開くワードを開くメニュー](<./images/FilenewOpenWord-ja.jpg>)

### 2-1. 新規作成する

新しいMarkdown文書を作成するには、メニューバーの **ファイル > 新規作成（⌘N）** を選択します。

作業中の内容がある場合は、必要に応じて保存してから新規作成してください。  
新規作成時には、現在の内容を履歴に保存してから新しい文書を作成する確認が表示されることがあります。

### 2-2. 既存のファイルを開く

作成済みのMarkdownファイル（`.md`、`.txt`、`.markdown` など）の編集を再開するには、以下の手順でファイルを選択します。

**① ファイルを開く操作**
以下のいずれかの方法で、ファイル選択画面を呼び出します。
* **メニューバーから:** **ファイル > 開く** をタップ（キーボード利用時は `⌘ + O`）
* **タイトルバーから:** **開く** ボタンをタップ

**② 『ファイル』アプリから選択**
iPad標準の『ファイル』アプリが開くので、対象のファイルを選択してください。

> **💡 クラウドストレージの利用**
> 『ファイル』アプリと連携しているため、iPad本体（このiPad内）だけでなく、**iCloud Drive** や **OneDrive** などのクラウドストレージに保存されているファイルも直接開くことができます。

### 2-3. Wordファイルを読み込む

お手持ちのWordファイル（`.docx`）を読み込んで、Markdownに変換して編集を開始できます。  
メニューバーの **ファイル > Wordファイルを開く (.docx)** を選択し、ファイルを選ぶと自動的に変換されます。

ファイルサイズの上限は **10MB** です。

> **注意:** Wordファイルの読み込みは、本文構造をMarkdownに変換するための機能です。Word上の細かなレイアウト、フォント、余白、図表、脚注、複雑な表などは、完全には再現されない場合があります。読み込み後は、Preview画面で内容を確認してください。

> **注意:** Wordファイルを読み込むと、現在の編集内容を置き換える確認が表示されます。必要な内容は、事前に **ファイル > 保存（⌘S）** で保存してください。

## 3. 本文を入力する



本文は、画面中央または左側の **エディター画面** に入力します。  
MD//WORKS Editorでは、Markdown形式で文章を作成できます。

> 💡 ソフトウェアキーボードでのカーソル移動: キーボードの『空白（スペース）』キーを長押しすると、キーボード全体がトラックパッドのように変わり、指を滑らせてカーソルを正確な位置へ素早く移動できます。

### 3-1. 基本的な入力例

以下は基本的なマークダウンの入力例です。エディター画面にペーストした後に、プレビュー画面で確認してみましょう。

```markdown
# 見出し1

これは本文です。

## 見出し2

- 箇条書き
- 箇条書き

**太字** や *斜体* も使えます。

> 引用

```

### 3-2. 画像を挿入する


小さなローカル画像は、エディター画面へドラッグ＆ドロップして挿入できます。iPadでは、Split View（画面分割）機能を使って、画面の半分に『写真』アプリや『ファイル』アプリを開き、そこから画像を長押ししてエディター画面へ直接ドラッグ＆ドロップするのが便利です。

画像を挿入すると、Markdown内に画像データとして追加されます。  
ただし、ローカル保存容量を圧迫しないよう、挿入できる画像サイズには制限があります。

対応の目安は次のとおりです。

| 項目 | 内容 |
| --- | --- |
| 画像サイズ | 200KB以下 |
| 対応画像 | PNG、JPEG、WebPなど |
| 非対応画像 | SVG画像 |

SVG画像は安全性のため挿入できません。必要に応じてPNG、JPEG、WebPなどに変換してから挿入してください。

### 3-3. 入力状況を確認する



長文の下書き、技術メモ、仕様書、議事録、研究メモなどをMarkdown形式で作成できます。  
入力中の行数、単語数、文字数は画面下部のステータスバーに表示されます。

## 4. 文章を装飾する



文章の装飾は、Markdown記法を直接入力する方法と、ツールバーを使う方法があります。

ツールバーを使うと、Markdown記法を覚えていなくても、見出し、太字、リスト、引用、コード、リンク、表などを簡単に挿入できます。

### 4-1. 見出しを作る



見出しを作るには、ツールバーの **H1 / H2 / H3** ボタンを使用します。

| ボタン | 内容 | Markdown例 |
| --- | --- | --- |
| H1 | 大見出し | `# 見出し` |
| H2 | 中見出し | `## 見出し` |
| H3 | 小見出し | `### 見出し` |

### 4-2. 太字・斜体・取り消し線を付ける



文字を選択してから、ツールバーのボタンを押すと、選択した文字に装飾を付けられます。

| ボタン | 内容 | Markdown例 |
| --- | --- | --- |
| B | 太字 | `**太字**` |
| I | 斜体 | `*斜体*` |
| S | 取り消し線 | `~~取り消し線~~` |

インラインコードは、文字の前後をバッククォートで囲みます。

```markdown

例1：<code>コード</code>
例1：`コード`

```

### 4-3. リスト・タスク・引用を作る


箇条書きやタスク管理用のチェックリストも作成できます。エディター画面にペーストした後に、プレビュー画面で確認してみましょう。

```markdown
- 箇条書き
- 箇条書き

1. 番号付きリスト
2. 番号付きリスト

- [ ] 未完了タスク
- [x] 完了タスク

```

### 4-4. コード・リンク・表を挿入する


技術メモや仕様書を作成する場合は、表やコードブロックも便利です。エディター画面にペーストした後に、プレビュー画面で確認してみましょう。

```markdown
| 項目 | 内容 |
|---|---|
| ファイル形式 | Markdown |
| 保存形式 | .md |

> 引用文
```

## 5. プレビューで確認する

Preview機能を使うと、前述のようにエディタ画面で入力したテキストが実際にどのように表示されるかを確認できます。マークダウンの表記法の多くは簡単ですが、表のような複雑な表記においてはPreview機能で確認することで、表記の間違いを防ぐことができます。

### 5-1. Previewを表示する

Previewを表示または非表示にするには、次のいずれかを使用します。

* タイトルバーの **Preview** ボタンをタップする
* メニューバーの **表示 > Preview** を選択する

PreviewをONにすると、画面右側にプレビュー画面が表示されます。  
左側でMarkdownを編集すると、右側のプレビューに反映されます。

### 5-2. Preview画面で確認できる内容

* 見出しの大きさ
* 太字・斜体などの装飾
* 箇条書き・番号付きリスト
* チェックリスト
* 表
* 引用
* コードブロック
* 画像

Preview画面は、完成後の見た目を確認するための表示エリアです。  
本文の編集は、左側のエディター画面で行います。

## 6. ファイルを保存（共有）する



作成した文書は、Markdownファイルとして保存できます。

### 6-1. Markdownファイルとして保存する

1. タイトルバーの **共有**ボタンをタップします。  
   または、メニューバーの **ファイル > 共有（⌘S）** を選択します。
2. 「ファイル」アプリから必要に応じて保存先を選択します。
3. Markdownファイルとして保存されます。


### 6-2. ファイル名や保存先フォルダを変更する（「名前を付けて保存」に相当）

タイトルバーのファイル名欄をタップすると、ファイル名を直接変更できます。
たとえば、`untitled.md` を `meeting-note.md` や `manual-draft.md` のように変更できます。その後、保存（共有）を行う際に、iPadの「ファイル」アプリ側で保存先フォルダを指定することで、PCやMacの「名前を付けて保存」と同じように、新しいファイルとして任意の場所に保存することもできます。


### 6-3. 保存状態を確認する

![Image: Saved / Unsaved indicator highlighted](<./images/SaveUndUnsavedStatus.jpg>)

タイトルバーには、現在の保存状態が表示されます。

| 表示 | 意味 |
| --- | --- |
| Saved | 保存済み |
| Unsaved | 未保存の変更あり |

編集後に保存していない内容がある場合は、保存状態が変化します。  
作業を終える前に、保存状態を確認してください。

### 6-4. ローカル下書きの保護を理解する

MD//WORKS Editorでは、下書きや履歴などのローカル保存データを平文のまま保存しないよう、**Auto encrypted** による保護が行われます。  
さらに保護を強めたい場合や、データを完全に消去したい場合は以下の機能を利用できます。

* **Private Storage**：自分だけのパスフレーズを設定し、ブラウザ内の下書き・履歴を追加保護します。
* **ローカル保存データ削除**：ファイルメニューの **Storage Security** 内にあり、ブラウザに保存された保護下書きや履歴を完全に消去します。

> **重要:** Auto encrypted や Private Storage は、ブラウザ内の下書き・履歴を保護する機能です。正式なファイル保存の代わりではありません。作業を確実に残すには、必ず **ファイル > 保存（⌘S）** で `.md` ファイルとして保存してください。iPadにおいては、編集中に他のアプリやホーム画面に移動すると、ブラウザがメモリを解放し、Auto encrypted による復元が失敗するケースが確認されています。

### 6-5. Private Storage と 暗号化Appの違い

**Private Storage** と **暗号化Appとして保存** は、どちらもパスフレーズを利用できますが、目的が異なります。

| 機能 | 目的 | 保護対象 |
| --- | --- | --- |
| Private Storage | 現在使っているブラウザ内の下書き・履歴を保護する | ブラウザ内のローカル保存データ |
| 暗号化Appとして保存 | 現在の原稿をパスフレーズ付きHTMLファイルとして書き出す | 書き出したHTMLファイル |

どちらもパスフレーズを忘れると復元できません。重要な原稿は、Markdownファイル（`.md`）としても別途保存してください。

### 6-6. 作業履歴から復元する



**ファイル > 作業履歴** を選択すると、保存された下書き履歴を確認できます。  
誤って内容を消してしまった場合や、以前の下書きに戻したい場合に使用します。

ただし、**ローカル保存データ削除** を実行すると、履歴も削除されます。  
大切な文書は、履歴だけに頼らず、Markdownファイルとして保存してください。

### 6-7. OS・ブラウザ別 ファイル保存・上書きの挙動

MD//WORKS Editor は、MacOSやiPadOSなど、さまざまな環境で利用できます。 ご利用の端末（OS）とブラウザの組み合わせにより、ファイルの保存および「上書き保存（ダウンロード）」の挙動が異なります。

| OS / プラットフォーム | Safari | Firefox | Brave | Chrome / Edge |
| ------------------- | ------ | ------- | ----- | ------------- |
| **macOS** | 直接上書き不可。<br>**番号付きのサフィックス**を付けた新しいファイルとしてダウンロードされます。| **Safari** と同じ。 | 任意のフォルダに「名前を付けてDL」で**手動で上書き可能**。 | 初回保存以降、**直接上書き**が可能。 |
| **iPadOS** | 直接上書き不可。**Files アプリ**経由で、**任意のフォルダ**に番号付きサフィックスを付けた新しいファイルとして保存されます。 | | | |





> **💡 iPadでの快適なファイル管理のコツ（疑似的な上書き保存）**
> iPadでは仕様上「直接の上書き保存」ができず、保存のたびに末尾に番号（1, 2...）が付いた新しいファイルが作成されます。これをPCと同じような感覚で快適に管理するために、以下の運用がおすすめです。
> 
> 1. iPadの『ファイル』アプリ上に、**「作成したいファイル名」と同じ名前の新しいフォルダ**を作成します。
> 2. エディタから保存（共有）する際、常にそのフォルダを保存先に指定します。
> 
> この方法をとることで、1つのフォルダ内に編集履歴が時系列（番号順）で自動的に蓄積されます。最新のファイルがどれかひと目で分かるだけでなく、**過去のバージョンにいつでも戻れる強力なバックアップ**として機能するため、MacやPCと変わらない、あるいはそれ以上に安心な運用が可能です。

## 7. HTML・PDFに書き出す


MD//WORKS Editorでは、Markdownファイルとして保存するだけでなく、用途に応じて複数の形式で書き出しできます。

### 7-1. スタンドアロン保存



**ファイル > スタンドアロン保存** を選択すると、現在の原稿を含んだスタンドアロンHTMLとして書き出せます。  
英語表示では **Save as App** と表示されます。

この形式では、エディター本体と原稿を1つのHTMLファイルにまとめることができます。  
ネットワーク環境がない場所でも開けるため、持ち運びや配布に便利です。

### 7-2. 暗号化Appとして保存


**ファイル > 暗号化Appとして保存** を選択すると、現在の原稿をパスフレーズ付きのHTMLファイルとして書き出せます。  
英語表示では **Save as Private App** と表示されます。

下書きや個人用メモ、機密性の高い原稿などを扱う場合に使用します。  
パスフレーズを忘れると本文を復元できません。必ず安全な場所に保管してください。

### 7-3. HTMLとしてエクスポート


**ファイル > HTMLとしてエクスポート** を選択すると、MarkdownをHTML形式で書き出せます。  
英語表示では **Export as HTML** と表示されます。

Markdownをブラウザで表示したい場合や、Webページ形式で共有したい場合に使用します。

### 7-4. 印刷 / PDF保存



**ファイル > 印刷 / PDF保存** を選択すると、ブラウザの印刷画面が開きます。  
印刷画面で保存先を「PDFに保存」に設定すると、PDFとして出力できます。  
英語表示では **Print / Save as PDF** と表示されます。

提出用PDFを作成する場合は、出力後に必ずPDFを開いて、見出し、表、画像、改ページを確認してください。

### 7-5. エクスポート形式を使い分ける

| 目的 | おすすめ操作 |
| --- | --- |
| Markdown原稿として保存したい | ファイル > 保存 |
| アプリごと1ファイルで持ち運びたい | ファイル > スタンドアロン保存 |
| パスフレーズ付きHTMLとして保存したい | ファイル > 暗号化Appとして保存 |
| HTMLとして表示・共有したい | ファイル > HTMLとしてエクスポート |
| 印刷・提出用にしたい | ファイル > 印刷 / PDF保存 |

## 8. 検索・置換する



MD//WORKS Editorでは、文書内の文字列を検索したり、特定の語句をまとめて置換したりできます。  
長い原稿、議事録、仕様書、研究メモなどを編集する場合に便利です。

### 8-1. 検索する


文書内の文字列を検索するには、メニューバーの **編集 > 検索（⌘F）** を選択します。

#### 操作手順

1. メニューバーの **編集** をクリックします。
2. **検索** を選択します。
3. 検索欄に探したい文字を入力します。
4. 一致した文字列がエディター画面上でハイライト表示されます。
5. **↑ / ↓** ボタンで前後の検索結果へ移動できます。

### 8-2. 置換する


文字列を別の文字列に置き換えるには、**編集 > 置換（⌘H）** を選択します。

#### 操作手順

1. **編集 > 置換** を選択します。
2. 上段に検索したい文字を入力します。
3. 下段に置き換えたい文字を入力します。
4. 1件ずつ置き換える場合は **置換** をクリックします。
5. すべてまとめて置き換える場合は **すべて置換** をタップします。

### 8-3. 検索オプションを使う



検索・置換パネルでは、次の検索オプションを使用できます。

| 項目 | 内容 |
| --- | --- |

## 9. 表示を切り替える



表示設定では、Preview、アウトライン表示、不可視文字、テーマ、全画面表示、Spell (EN)、Zenモードなどを切り替えできます。

**表示 > Preview** を選択すると、プレビュー画面の表示・非表示を切り替えできます。

### 9-3. 不可視文字を表示する



**表示 > 不可視文字を表示** を選択すると、通常は見えない文字を視覚的に確認できます。

表示対象の例は次のとおりです。

| 表示対象 | 用途 |
| --- | --- |

| タブ | インデントの確認 |
| 行末スペース | Markdown崩れの原因確認 |
| 改行位置 | 段落やリストの確認 |

Markdownでは、スペースや改行の位置が表示結果に影響することがあります。  
原稿の体裁を整えるときに便利です。

### 9-4. テーマを変更する



**表示** メニューから、画面テーマを切り替えできます。

| テーマ | 特徴 |

| Paper | 白背景の文書作成向けテーマ |
| Warm | 長文執筆向けの目にやさしいテーマ |

文書作成やレビュー時は **Paper**、長時間の執筆時は **Warm**、集中して編集したいときは **Midnight** など、用途に応じて切り替えできます。

>💡 **Apple Pencilをより快適に使うヒント**：黒背景の「Midnight」テーマは、スクリブル（手書き入力）機能との相性が抜群です。画面上でペンの軌跡の色が変わる瞬間がはっきりと分かるため、手書きから文字変換されるタイミングが掴みやすく、テンポ良く執筆を進めることができます。

### 9-5. 全画面表示にする



**表示 > 全画面表示**、またはタイトルバーの全画面表示ボタンを使うと、ブラウザを全画面表示にできます。

画面を広く使いたい場合や、文書全体を確認したい場合に便利です。

> * **外付けキーボードを使う:** Magic Keyboardなどのハードウェアキーボード接続時も、画面を広く保ったままタイピングが可能です。


### 9-6. Spell (EN) を使う



**表示 > Spell (EN)**、またはタイトルバーの **Spell (EN)** ボタンで英語スペルチェックを切り替えできます。

主に英語テキストの確認に向いています。日本語文章の校正機能ではありません。

### 9-7. Zenモードで集中する



**表示 > Zenモード（集中モード）** を選択すると、メニューやツールバーなどを隠し、本文入力に集中できる表示になります。

長文の下書き、原稿執筆、集中して推敲したい場面で便利です。  
解除する場合は、画面右上の **✕** ボタンを押します。

## 11. AI支援執筆 ![Image: Geminiに相談ボタン](<images/Bgemni.png>) ![Image: LeoImage](<images/Leoimage.png>)

MD//WORKSは、単なるテキスト入力・編集だけでなく、Chrome GeminiなどのブラウザAIと組み合わせてより活用することができます。

AI機能はMD//WORKS本体に内蔵されているものではありませんが、表記ゆれの修正や翻訳といった機械的な作業はもちろん、Markdown形式で書かれた文章構成の客観的なレビュー、コードの説明、参考文献メモの整理等、執筆中のさまざまな作業の補助に活用可能です。

これにより、文章作成時の認知負荷を減らし、より創造的な作業や内容の検討に集中しやすくなります。本章では、設定準備と具体的な活用方法に加え、用途によるブラウザAIの注意点について解説します。

### 11-1. AI執筆支援を使う準備

iPadではBraveを利用することでAI執筆支援が可能です。。

#### 11-1-1. Brave Browser: Leoの利用
1. ログインは不要です。「...」メニュー内のAIチャットマーク![Image: LeoImage](<images/Leoimage.png>)でAIチャットのタブが開きます。
2. MD//WORKSで編集していた直前の内容がAIの解析対象となります。コピーペストせずにカーソルで選択だけで対象の限定が可能です

>特徴：Googleアカウント不要で、プライバシーを保ったまま利用が可能です。iPadを含むモバイル環境でも、PC版とほぼ同等のDOM解析精度で動作することが確認されており、複雑なページ構造や粗雑なHTML構造でも安定してテキストを読み取ることができます。

### 11-2. 活用事例
日常的な校正、要約、用語ゆれ確認、章構成の見直しには、軽量なモデルを使用する方が、短時間に提案が得られ、執筆に集中できます。通常の執筆時はFlashに固定しておき、「長文全体の構成レビュー」や「日本語と英語の細かなニュアンスの整合性チェック」など、高度な比較・検証が必要な場面でのみ各社のフロンティアモデルに切り替えるといった運用を推奨します。以下に具体的なプロンプトの例を挙げました。

* 文章全体を300字程度で要約して

* この章の見出しだけを抜き出して

## 12. よくあるトラブル


ここでは、MD//WORKS Editorを使用中によくある問題と対処方法をまとめます。

### 12-1. 編集画面で Home / End キーを押しても、文書の先頭や末尾に移動しません。

編集画面では文字入力や編集をスムーズに行えるよう、Home / End キーは**現在行の先頭・末尾への移動**に割り当てられています。（※Preview 画面では、文書全体の先頭・末尾へ移動します）
> 文書全体の先頭・末尾へ移動したい場合は、以下のショートカットをご利用いただけます。
> * **⌘ + ↑ ：文書の先頭へ移動
> * **⌘ + ↓ 


### 12-2. 保存したはずなのに内容が見つからない

まず、ブラウザのダウンロードフォルダを確認してください。  
保存やエクスポートの操作では、お使いのブラウザの設定に従ってファイルが保存されます。ファイル名欄に表示されている名前と、実際に保存されたファイル名が一致しているかも確認してください。

また、Auto encrypted はブラウザ内の下書き・履歴を保護する機能であり、PC上に `.md` ファイルを作成する機能ではありません。正式なファイルとして残す場合は、必ず **ファイル > 保存（⌘S）** を実行してください。

### 12-3. 「Unsaved」と表示される



**Unsaved** は、最後に保存した後に変更が加えられている状態を示します。  
作業を終了する前に、**保存** ボタンまたは **ファイル > 保存（⌘S）** で保存してください。  
保存が完了すると、表示は **Saved** に戻ります。

### 12-4. メニューから貼り付けができない

ブラウザの制限により、メニュー操作からの貼り付けがブロックされる場合があります。  
その場合は、キーボードショートカット **⌘V** を使用してください。

### 12-5. 画像を挿入できない

画像をドラッグ＆ドロップしても挿入できない場合は、次を確認してください。

| 確認項目 | 対処方法 |
| --- | --- |
| 画像サイズが大きい | 200KB以下に圧縮してください |
| SVG画像を使っている | PNG、JPEG、WebPなどに変換してください |
| 画像ではないファイルをドロップしている | 画像ファイルを選択してください |

MD//WORKS Editorでは、ローカル保存容量と安全性を守るため、200KBを超える画像とSVG画像は挿入できない仕様です。

### 12-6. Previewが表示されない

Previewが表示されない場合は、タイトルバーの **Preview** ボタン、または **表示 > Preview** を選択しているか確認してください。  
画面幅が狭い場合は、Previewが全画面または折りたたみ表示になる場合があります。  
表示中は、中央の分割バーをドラッグして編集画面とPreview画面の幅を調整できます。

### 12-7. 検索結果が見つからない

検索しても結果が出ない場合は、大文字小文字の区別、単語単位、正規表現などの検索オプションの設定を確認してください。  
全角・半角の違いや、目に見えない余分なスペースが原因のこともあります。必要に応じて **表示 > 不可視文字を表示** をONにして確認してください。

### 12-8. 正規表現エラーが出る



検索オプションで **正規表現** をONにしている場合、入力内容が正規表現として解釈されます。  
記法が誤っているとエラーになります。正規表現を使わない場合は、**正規表現** のチェックを外してください。

### 12-9. Spell (EN) が反応しない

Spell (EN) は主に**英単語向け**の機能です。日本語の校正機能ではありません。  
ONになっているか確認し、英語テキストが入力されているか確認してください。ネットワーク環境によっては辞書データの読み込みに数秒かかる場合があります。

### 12-10. Private Storageのパスフレーズを忘れた

Private Storageのパスフレーズを忘れると、保存された下書きや履歴を復元することはできません。  
重要な原稿は、Private Storageだけに頼らず、Markdownファイル（`.md`）として別途PC内に保存しておくことをおすすめします。

### 12-11. 暗号化Appのパスフレーズを忘れた

**ファイル > 暗号化Appとして保存** で作成したHTMLファイルは、パスフレーズが正しくないと本文を復元できません。  
パスフレーズを忘れた場合、原則として内容を復元できません。

暗号化Appを作成する場合は、元のMarkdownファイルも別途安全な場所に保存しておくことをおすすめします。

### 12-12. スタンドアロンHTMLがうまく開かない

スタンドアロンHTMLや暗号化Appがうまく開かない場合は、次を確認してください。

| 確認項目 | 対処方法 |
| --- | --- |
| 暗号化Appのパスフレーズが違う | 正しいパスフレーズを入力する |
| ファイルが壊れている | 再度書き出す |

暗号化Appの作成・復号には、最新版のブラウザを推奨します。

### 12-13. PDF出力がうまくいかない

PDF出力（**ファイル > 印刷 / PDF保存**）は、ブラウザの印刷機能を利用しています。  
印刷画面で保存先を「PDFに保存」に設定し、用紙サイズや余白を確認してください。

提出用PDFを作成する場合は、出力後に必ずファイルを開いて、レイアウト崩れがないか確認してください。
